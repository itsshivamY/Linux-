# 23. `int main()` IN C/C++

C aur C++ program mein commonly:

```c
#include <stdio.h>

int main()
{
    printf("Hello World");
    return 0;
}
```

### Why `main()`?

`main()` program ka standard **entry point** hai.

Program execution normally `main()` se start hota hai.

### Why `int`?

`int` indicate karta hai ki `main()` ek integer status value return karta hai.

### Why `return 0`?

```c
return 0;
```

Generally indicate karta hai ki program successfully complete hua.

### Flow

```text
Operating System
       ↓
     main()
       ↓
   printf()
       ↓
  return 0
       ↓
Program ends
```
